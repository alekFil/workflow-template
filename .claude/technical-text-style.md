# Технический текст: русский аналог ASD-STE100

Источник: стандарт ASD-STE100 Simplified Technical English, перенесенный на русский язык.

Файл на русском в обход конвенции «`.claude/` пишем по-английски»: правила перечисляют русские
обороты.

## Где действует

Правило действует для всего русского текста в репозитории: документация, `README.md`,
слайды презентаций, отчеты, тела коммитов и ответы владельцу в чате.

`.claude/writing-style.md` применяется, только если владелец отдельно просит об этом.
Буква ё не используется нигде. Тире только короткое.

## Слова

Один термин имеет одно значение. Одна вещь имеет один термин.
Синонимы для разнообразия не используются.
Выбери термин в начале документа. Используй только его до конца документа.

Используй простое слово, если оно есть.
Не используй разговорные слова, жаргон и переносные значения.
Имя таблицы, колонки, файла и команды пиши точно как в источнике.

Не ставь подряд больше трех существительных.
Пиши «проверка типа колонки», а не «результат проверки типа колонки таблицы».

Не используй вводные слова: «следует отметить», «как правило», «в целом», «по сути».
Оценку отмечай одним постоянным словом: «Оценка:».

## Глаголы

Используй действительный залог. Называй того, кто действует.
Пиши «модель оценивает заявку», а не «заявка оценивается моделью».

Используй настоящее время для описания. Используй прошедшее время для факта, который произошел.
Используй повелительное наклонение для инструкции: «запусти», «проверь».

Заменяй отглагольное существительное глаголом.
Пиши «отчет считает AUC», а не «отчет выполняет расчет AUC».

Не используй причастные и деепричастные обороты, если их заменяет отдельное предложение.

## Предложения

Одно предложение содержит одну мысль.
Предложение описания содержит не больше 25 слов.
Предложение инструкции содержит не больше 20 слов.

Одно предложение инструкции содержит одно действие.
Два действия идут в одном предложении, только если их выполняют одновременно.

Условие ставь перед действием: «Если версии нет, выпусти датасет».
Предупреждение ставь перед шагом, к которому оно относится.

Не пропускай слова ради краткости. В предложении есть подлежащее и сказуемое.
Исключение одно: ячейка таблицы «имя – назначение». Там подлежащее стоит в первой колонке.

## Абзацы

Один абзац содержит одну тему. Первое предложение называет тему.
Абзац содержит не больше шести предложений.
Короткие предложения одного абзаца можно писать с новой строки.

## Списки, таблицы, код

Список используй только для перечня. Не используй список для выделения.
Таблицу используй для перечня «имя – назначение». Ячейка содержит короткие предложения.
Не делай широкую таблицу с длинными ячейками, если ее заменяют две колонки.
Границы таблицы выравнивай.

Не используй блок кода на одну строку для выделения. Имя в тексте ставь в обратные кавычки.
Блок кода используй для команды, которую читатель запускает, и для образца из нескольких строк.

## Числа

Число пиши цифрами. Единицу измерения пиши рядом с числом.
Один показатель имеет один формат во всем документе.

## Чего в тексте нет

Нет истории изменений и причин решений. Для них есть журнал решений.
Нет оценочных слов: «важный», «ключевой», «простой», «удобный».
Нет обещаний и планов. Для них есть список задач.
