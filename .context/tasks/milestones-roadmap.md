# Роадмап из карточек: поле milestone

Владелец хочет видеть роадмап: какие задачи входят в какой этап, например `v2` и
`v3`. Отдельный файл `roadmap.md` со списком задач повторяет данные карточек и
расходится с ними. Каждая ветка задачи правит его, и параллельные ветки конфликтуют.

Нужно: роадмап генерируется из карточек, как индекс ADR.

- Необязательное поле `milestone` во frontmatter карточки: `artifacts.md`, `/task`.
- `workflow.sh tasks` группирует открытые карточки по `milestone`. Карточки без поля
  идут в группу «без этапа».
- `/report` показывает роадмап в `.context/status.md`.
- По желанию: `/close` пишет трейлер `Milestone:`, `workflow.sh done` группирует
  закрытые задачи по этапам.
- Направление этапа словами, 2–3 строки, – в `PRODUCT_FILE`, а не в отдельном файле.

Изменение идет в оба слоя.
