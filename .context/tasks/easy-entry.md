# Легкий вход: минимальный путь в README и установка по умолчанию

Позиционирование шаблона: «начни один за 5 минут, вырасти в команду без конфликтов в
контексте, вноси вклад в OSS без следов агента». Сейчас шаблон дает 15 скиллов,
3 профиля, 2 режима ветвления и файл настроек. Для нового пользователя это не легкий
вход.

Нужно:

- начало `README.md` показывает минимальный путь из 3 команд: `/task` → `/architect`
  → `/go`. `/go` закрывает задачу сам, отдельный `/close` не нужен. Остальные скиллы
  идут ниже, в разделе «когда понадобится»;
- ответ Enter на все вопросы `install.sh` дает рабочий одиночный проект. Проверить
  это и исправить расхождения;
- демо от установки до закрытой задачи – карточка `demo-recording`.
