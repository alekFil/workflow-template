# Агент не обещает отменить запись на GitHub

В том же прогоне агент написал, что запись в задаче оригинала «можно удалить вместе
с PR». Pull request на GitHub удалить нельзя, его можно только закрыть. Закрытие
запись `cross-referenced` не убирает.

Нужна формулировка в `.claude/rules/profiles.md` или в `/close`: pull request,
комментарий, упоминание и push необратимы. Агент не обещает отмену. Если способ
отмены неизвестен, агент так и пишет.

Связано с `upstream-reference-guard`. Изменение идет в оба слоя.
