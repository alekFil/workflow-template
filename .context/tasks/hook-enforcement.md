# Жесткий контроль инвариантов через хуки

Перейти от мягкого контроля (текст скилла и дисциплина модели) к хукам для критичных
инвариантов. Границы скиллов целиком хуками не закрыть: хук не знает, какой скилл
работает. Инварианты состояния и грубые действия закрываются.

1. Описать модель: какие правила – жесткий хук, какие остаются мягкими, критерии.
2. Уровень 1, инварианты: предупреждение, если план карточки задачи не закоммичен на
   ветке задачи; запрет правки сгенерированных индексов руками.
3. Уровень 3, запрет опасных действий (`PreToolUse`): `git push` вне `MERGE_MODE=pr`,
   `git commit` на `main` и `dev`, `git commit --amend`, `git rebase -i`,
   `git reset --hard`.
4. Перенести хуки в `template/.claude/settings.json`.
5. Git hooks как дополнение для людей без агента: `pre-commit` с проверкой тире и ё.
6. Уровень 2 (напоминания в промпте) – отложить как эксперимент.
