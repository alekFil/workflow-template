## About this repo

`workflow-template` – a workflow template repository for Claude Code. Contains the
documentation structure, workflow skills and rules. Used as the foundation when
starting a new project.

### Two layers

- **Maintainer** (root): `CLAUDE.md`, `CONTRIBUTION.md`, `.context/`, `.claude/`,
  `scripts/`
- **Template** (`template/`): everything that goes into a new project when deployed
  via `scripts/install.sh`

The two layers keep independent copies of skills and rules. A change to one layer is
carried to the other on purpose, in the same task.

Claude Code also discovers `template/.claude/skills/` as nested skills
(`template:<name>`) when it works with files there. Use the root skills for work on
this repo.

## Components

- `.claude/` – Claude Code tooling: skills, rules
- `.context/` – workflow artifacts: blueprint, task cards, status, discussions,
  retros, private notes
- `docs/` – product description (`product.md`) and decisions (`decisions/`)
- `scripts/` – user-facing installers (install/uninstall via curl)
- `template/` – payload deployed into new projects
- Top-level: `CLAUDE.md`, `CONTRIBUTION.md`, `SETUP.md`, `README.md`, `LICENSE`

Physical file tree – `.context/status.md` (generated by `/report`).

## Modes

The owner switches modes with skills. Each skill holds its full instructions.

- `/organize` – template improvements: `CLAUDE.md`, `CONTRIBUTION.md`, skills and
  rules of both layers
- `/architect` – design of changes in template structure or skills, no edits
- `/dev` – implementation of the plan

The full command list – `template/WORKFLOW.md`.

## Workflow rules

Rules in `.claude/rules/` load automatically:

- `artifacts.md` – where documents live, task cards, conflict-free shared text
- `adr-discipline.md` – what is an ADR and what is a commit message
- `branching.md` – branch model and merges
- `skill-boundaries.md` – a skill does not run its neighbor automatically
- `text-conventions.md`, `markdown-conventions.md`, `technical-text-style.md` – text
  and markup
- `no-placeholder-leaks.md` – `template/` keeps its placeholders

`.claude/skills/writing-style/SKILL.md` applies only when the owner asks for it
explicitly.

## Maintaining this template

### Syncing improvements from real projects

If a skill or workflow improvement appeared in a working project:

1. Open a session with this repo
2. Transfer the change manually:
   - skill → `.claude/skills/<name>/` and/or `template/.claude/skills/<name>/`
   - rule → `.claude/rules/` and/or `template/.claude/rules/`
   - `CLAUDE.md` → `template/CLAUDE.md`
3. Commit: `/commit`

### Skill versioning

Skills are not explicitly versioned. Change history – in git log and
`docs/decisions/`. Tag `v1` marks the workflow before the 2026-11 redesign.

### What NOT to touch

- All files in `template/` keep `{PLACEHOLDERS}` – do not fill with real data.
- `template/.context/` folders with `.gitkeep` – needed for structure.
- `template/docs/decisions/README.md` – the empty generated index.
