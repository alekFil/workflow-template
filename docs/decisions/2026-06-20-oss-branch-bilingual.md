# Ветка `oss` и двуязычие шаблона

**Контекст:** OSS-публикация (ADR-014) требует рабочей ветки и решения по языку шаблона.

**Решения:**

1. **Ветка `oss`** – долгоживущая рабочая ветка для OSS-публикации. Выбрана вместо `feature/oss-publication` для краткости и потому что curl-команды удобно тестировать прямо с этой ветки (`…workflow-template/oss/scripts/…`). Сольется в `main` по завершении.

2. **«Respond in the user's language»** – в `template/CLAUDE.md` добавляется явная инструкция: CC отвечает на языке пользователя. Шаблон работает для любой языковой аудитории.

3. **Слэш-команды объединяются с фазой Б** – замена ключевых фраз на слэш-команды делается вместе с переводом `template/CLAUDE.md`. Фаза В остается только: переписать README и снять демо.

**Имена слэш-команд** (зафиксированы при реализации фазы Б):

| Команда | Было (ключевая фраза) | Режим/скилл |
| --- | --- | --- |
| `/organize` | `организуем работу` | Режим Организатора |
| `/architect` | `обсудим` | Режим Архитектора |
| `/next` | `что дальше` | Следующая задача |
| `/record` | `записываем решение` | ADR в decisions.md |
| `/dev` | `начинаем реализацию` | Режим Разработчика |
| `/close` | `закрываем задачу` | cc-close-task.md |
| `/status` | `текущий статус` | cc-status-report.md |
| `/sync` | `синхронизируем` | cc-architect-sync.md |
| `/commit` | `фиксируем` | cc-commit.md |

**Последствия:**

- Мейнтейнерский слой (`main`) остается на русском
- Ветка `oss` ведется параллельно и не мержится до завершения OSS-публикации
