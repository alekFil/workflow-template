# Явная языковая настройка в установщике и CLAUDE.md

**Контекст:** `template/CLAUDE.md` содержал инструкцию «Respond in the user's language», которая заставляла CC угадывать язык из контекста диалога. Это работало неявно и не давало пользователю возможности задать разные языки для разных областей (общение, рабочие документы, комментарии в коде).

**Решение:** Заменить динамическое правило на явную Language-секцию с тремя плейсхолдерами: `{COMMUNICATION_LANGUAGE}`, `{CONTEXT_LANGUAGE}`, `{CODE_COMMENTS_LANGUAGE}`. Workflow-документы (`.claude/`, skills, команды) зафиксированы как English – без плейсхолдера. В `install.sh` добавлен блок вопросов с выбором [one/multi]: при `one` все три оси автоматически выставляются в English, при `multi` задаются отдельно. Мейнтейнерский `CLAUDE.md` обновлен с реальными значениями (Russian / Russian / English / English). Упоминание языка комментариев убрано из `{CODE_CONVENTIONS}` – теперь это единственное место для языковых настроек.

**Последствия:**

- `template/CLAUDE.md` – Language-секция с 3 плейсхолдерами вместо расплывчатой строки; `{CODE_CONVENTIONS}` без упоминания Comment language
- `CLAUDE.md` (root) – Language-секция с явными значениями
- `scripts/install.sh` – новый блок языковых вопросов, 3 дополнительных `sed`-подстановки
