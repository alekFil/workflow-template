# Правила стиля текста в обоих слоях

**Контекст:** Владелец принес набор правил стиля из другого репозитория. Набор содержит
пять частей. `dash-conventions.md` запрещает длинное тире. `markdown-conventions.md`
описывает разметку. `technical-text-style.md` переносит ASD-STE100 на русский язык.
`writing-style.md` описывает стиль «как пишет человек». `CLAUDE-snippets.md` запрещает
букву ё и ограничивает строку 88 символами. До этого решения репозиторий содержал 759
длинных тире и 116 букв ё. Шаблон не привязан к языку: язык общения задает
плейсхолдер при установке. Правила о стиле и о букве ё работают только для русского
текста.

**Решение:**

1. **Шаблон получает весь набор без изменений.** `technical-text-style.md`,
   `writing-style.md` и `dash-conventions.md` лежат в `.claude/` обоих слоев.
   `markdown-conventions.md` теперь есть и в `template/`. Альтернатива «в шаблон только
   правила о тире и разметке» сохраняет языковую нейтральность. Но тогда русскоязычный
   проект настраивает стиль вручную. Альтернатива «перевести на английский» требует
   больше работы. При переводе правила, которые перечисляют русские обороты, теряют
   смысл. В англоязычном проекте русские правила ничего не меняют. Оценка: цена
   выбранного варианта ниже.
2. **Старый текст заменен сразу.** Длинное тире заменено на короткое, ё заменена на е во
   всех отслеживаемых файлах, включая `decisions.md` и `history/`. Альтернатива
   «исправлять только при правке абзаца» дает смешанный репозиторий на долгий срок.
   В нем `/polish` отмечает старые нарушения при каждом прогоне. Цена массовой замены:
   один большой diff, который затрагивает историю решений. Замена механическая, смысл
   текста она не меняет. Строки по 88 символов заново не переносились. Их переносят,
   когда правят абзац.
3. **Запрет bold вместо заголовка не возвращается.** Набор содержит это правило, но
   ADR-025 его отменил. Шаблоны ADR и статуса сами порождают `**Метка:**`. Возврат
   правила снова дает шум в `/polish`.
4. **Файлы стиля написаны на русском вопреки конвенции «`.claude/` на английском».**
   Исключение записано в разделе «Language» в `CLAUDE.md` обоих слоев.
5. **`CLAUDE.md` обоих слоев** получает раздел «Code conventions» с правилами о букве ё
   и о тире. Раздел «Markdown conventions» получает правило о длине строки и ссылки на
   файлы стиля. `technical-text-style.md` действует для всего русского текста и для
   ответов в чате. `writing-style.md` действует только по отдельной просьбе владельца.

**Последствия:**

- `/polish` получает правило `dash-conventions` в обоих слоях. Правило
  `markdown-conventions` проверяет длину строки только в новых и правленых абзацах.
- Новый проект после `install.sh` получает правила стиля и правило разметки.
- Заменяет п. 4 ADR-025: копия `markdown-conventions.md` в `template/` теперь есть.
  Остальные пункты ADR-025 действуют.
- `.markdownlint.json` не меняется: `MD013` выключен, потому что старый текст содержит
  строки длиннее 88 символов.
